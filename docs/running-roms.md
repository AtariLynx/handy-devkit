# Running ROMs from emulation RAM

THe Howard board allows ROMs to be uploaded into RAM memory where it can be run without any encrypted headers. The ROMs are binary files that have an empty header, which would normally be filled in by performing the encryption process.

## Steps to perform:

- Start `HowDebug`
- Power on the Howard board. `HowDebug` should indicate that the `Parallel Port is ACTIVE`. 
- Press `Shift+F4` to open the file requestor.
